## ✏️ Cara Mengisi
1. Buka file yang ingin kamu ubah di VS Code.
2. Cari bagian yang bertanda **`[ ... ]`** atau **`[ ISI DI SINI ]`**.
3. Ganti teks tersebut dengan data atau pilihanmu.
4. Jika sudah siap, kita bisa langsung mulai tahap coding pembuatan websitenya!
