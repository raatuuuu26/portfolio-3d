## 1. Pilihan Fondasi Web (Frontend Architecture)

  - [x] **Tailwind CSS v3 / v4** (Utility-first CSS, sangat fleksibel, mudah dikustomisasi tema)

---

## 2. Pustaka 3D & Animasi 360°

- **3D Engine**:
  - [x] **Three.js**: Pustaka 3D standar industri berbasis WebGL.
  - [x] **@react-three/fiber (R3F)**: Deklaratif Three.js wrapper untuk React.
  - [x] **@react-three/drei**: Kumpulan helper siap pakai (OrbitControls untuk putaran 360°, Float, Stars, Canvas loader).
- **Smooth Interaction & Motion**:
  - [x] **Framer Motion**: Animasi transisi teks, kemunculan kartu, dan hover effect yang mulus.
  - [x] **Lenis Smooth Scroll**: Memberikan pengalaman scroll halaman yang halus dan berbobot.
- **Ikon**:
  - [x] **Lucide React**: Kumpulan ikon modern, clean, dan ringan.
