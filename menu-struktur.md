# 🧭 Menu & Struktur Halaman Portofolio

> *File ini mendefinisikan navigasi menu dan urutan section (bagian) di website portofoliomu.*

---

## 1. Navigasi Atas (Navbar)
- **Tampilan Kiri**: `[ me.img ]`
- **Daftar Menu Navigasi**:
  1. `Home` -> Scroll ke Hero Section
  2. `About` -> Scroll ke bagian Tentang Saya
  3. `Skills` -> Scroll ke bagian Keahlian / Tech Stack
  4. `Projects` -> Scroll ke galeri proyek
  5. `Contact` -> Scroll ke bagian formulir kontak
- **Tombol Aksi di Navbar**:
  - [x] Tombol `"Download CV"`
  - [x] Tombol `"Hire Me"` / Kontak langsung
  - [ ] Toggle Dark/Light Mode
  - [ ] Toggle Suara Latar / Sound FX (opsional)

---

## 2. Susunan Section Halaman (Dari Atas ke Bawah)

### Section 1: Hero Section (Halaman Depan Utama)
- **Sapaan**: `"Halo, saya Ratu"`
- **Heading / Role**: Teks animasi dinamis
- **Sub-headline**: Ringkasan singkat tagline
- **Canvas 3D 360°**: Model 3D interaktif yang bisa diputar bebas oleh user
- **Call-to-Action (CTA)**:
  - Tombol Utama: `"Lihat Karya Saya"`
  - Tombol Kedua: `"Hubungi Saya"`

### Section 2: About Me (Tentang Saya)
- Foto profil / Ilustrasi
- Teks deskripsi diri
- Kartu statistik (Pengalaman, Proyek, dll.)

### Section 3: Skills & Keahlian
- Kategori keahlian (Frontend, Backend, Tools, dll.)
- Pilihan tampilan:
  - [ ] Grid kartu modern dengan efek hover glow
  - [ ] Bola kata 3D (3D Sphere Tag Cloud yang berputar)
  - [x] Interactive Badge Slider / Marquee bergerak

### Section 4: Showcase Proyek (Portfolio Gallery)
- Tab filter kategori (Semua, Web, Mobile, Desain 3D, dll.)
- Kartu preview proyek dengan tombol Live Demo & GitHub

### Section 5: Experience / Education (Timeline)
- Jejak riwayat kerja / pendidikan / sertifikasi

### Section 6: Contact Section
- Formulir kirim pesan (Nama, Email, Pesan)
- Info kontak langsung (Email, WhatsApp, Lokasi)

### Section 7: Footer
- Hak cipta & Tahun
- Tautan sosial media
- Tombol scroll kembali ke atas (Back to Top)
